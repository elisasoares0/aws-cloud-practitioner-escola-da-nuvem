# ☁️ AWS Cloud Practitioner - Escola da Nuvem

Repositório dedicado ao registro de estudos, resumos teóricos e laboratórios práticos realizados durante o curso de **AWS Cloud Practitioner** na **Escola da Nuvem**.

---

## 🚀 Sobre o Projeto
O objetivo deste repositório é documentar minha jornada de aprendizado em computação em nuvem, consolidando conceitos fundamentais de arquitetura, segurança, serviços essenciais da AWS e boas práticas de mercado.

---

## 🗂️ Progresso dos Módulos e Laboratórios

| Módulo | Tópicos Principais | Status | Acesso |
| :--- | :--- | :--- | :--- |
| **01. Introdução à Nuvem** | Conceitos fundamentais, benefícios, modelos (IaaS/PaaS/SaaS) e regiões/AZs | Concluído ✅ | [Ver Docs](./docs/01-introducao-nuvem/) |
| **02. Linux Essencial** | Terminal, gerenciamento de arquivos, permissões e pacotes | Concluído ✅ | [Ver Docs](./docs/02-linux-essencial/) |
| **03. Redes na AWS** | VPC, sub-redes públicas/privadas, Internet Gateway e Security Groups | **Em andamento 🔄** | [Ver Labs](./docs/03-redes-na-aws/) |
